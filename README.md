# 虚拟AI工作室 · Immersive AI Studio（V1）

网页沉浸式虚拟 AI 工作室平台：低多边形 3D 办公室场景中，3 个基础 AI Agent（规划 / 编码 / 创作）在各自工位工作，玩家可第一人称漫游、点击 Agent 查看详情、下发指令触发多 Agent 协作，右侧深色控制台实时流式展示 Agent 状态、思考日志与互相发送的消息。

页面布局参考开源项目 [arturitu/the-delegation](https://github.com/arturitu/the-delegation)（中间 3D 场景 + 右侧深色信息面板），美术采用简约低多边形风格，未照搬其任务看板与自动寻路逻辑。

## 运行方式

纯静态站点，无需构建、无服务端依赖：

```bash
# 方式一：任意静态服务器
python3 -m http.server 8080
# 打开 http://localhost:8080

# 方式二：直接部署到 GitHub Pages / 任意静态托管
```

> Three.js 已本地化到 `vendor/`，可离线运行；WebLLM 模型权重与 C++ 编译服务需要联网（首次加载后浏览器会缓存模型）。

## 操作说明

| 操作 | 说明 |
| --- | --- |
| `W A S D` / 方向键 | 第一人称移动 |
| `Shift` | 加速奔跑 |
| 鼠标（点击画布空白处） | 进入指针锁定沉浸模式，拖动旋转视角，`Esc` 释放 |

| 顶部按钮 | 打开 本地大模型对话 / C++ 编译器 / 代码文件 浮动面板 |
| 触屏设备 | 左下摇杆移动，单指拖动旋转视角 |

## 功能清单

### V1 本次新增

1. **Agent 四状态机**：空闲 / 思考 / 执行任务 / 对话。状态变化实时同步到 3D 头顶光环与状态珠（颜色区分）、右侧状态卡片、日志面板。
2. **右侧深色流式日志面板**：流式输出每个 Agent 的思考内容（打字机光标）、Agent 互相发送的消息记录（`发送方 → 接收方`）、状态变更与执行动作；支持 全部 / 思考 / 消息 / 系统 分类过滤、自动滚动、清屏。
3. **Agent 详情弹窗**：点击任意 Agent 小人弹出深色详情面板，展示名称、岗位、当前状态、当前任务、历史对话记录；支持「发起对话」与「定位视角」（传送玩家到该工位前）。

### 原有功能（保持不变）

- 玩家 3D 场景自由漫游 + AABB / 圆形碰撞检测（分轴解算，沿墙滑动）
- 3 个基础 Agent：规划Agent / 编码Agent / 创作Agent
- WebLLM 本地大模型对话（WebGPU 浏览器内推理，可选 Qwen2.5-1.5B / 3B、Llama-3.2-1B；未加载时自动进入演示模式）
- C++ 在线编译器（Wandbox 公共 API，Piston 兜底）
- 编码Agent 读取 / 修改虚拟文件系统中的代码（localStorage 持久化，修改后文件面板显示角标）

### V1 明确未开发

NavMesh 自动寻路、AI 自动走路移动、工位移动逻辑、Agent 开会聚集、Kanban 任务看板、自定义新增 Agent。

## 多 Agent 协作链路

```
用户指令 → 规划Agent（思考·流式输出拆解方案）
                └─ [TO:coder] 转派指令（消息记录入日志）
                        → 编码Agent（读取目标文件 → 生成代码 → 写入虚拟文件系统）
                                └─ 文件面板出现"编码Agent 修改过"角标
```

加载本地大模型后，上述思考与代码生成由浏览器内 WebLLM 真实推理产出；未加载时由演示模式模拟，完整链路依然可体验。

## 技术要点

- **渲染**：Three.js r166（WebGL2），`MeshStandardMaterial` + `flatShading` 低面数观感；`PCFSoftShadowMap` 软阴影；`FogExp2` 轻微雾化；像素比上限 2，平板友好。
- **碰撞**：玩家胶囊 vs AABB / 圆形碰撞体集合，X/Z 分轴解算实现沿墙滑动。
- **拾取**：基于画布矩形的 NDC 射线拾取（`Raycaster` + CSS2D 标签）。
- **持久化**：虚拟文件系统存于 `localStorage`。
- **UI**：全部深色自绘面板，无浏览器原生弹窗；`[hidden]` 全局优先，避免隐藏层拦截点击。

## 已知限制

- 本地大模型需要支持 WebGPU 的浏览器（Chrome 113+ / Edge 最新版）；不支持时自动使用演示模式，平台其余功能不受影响。
- C++ 编译与 WebLLM 模型下载需要联网。
- 测试环境为软件渲染（SwiftShader）时帧率较低属正常现象，真实 GPU 下流畅。
